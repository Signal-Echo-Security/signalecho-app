# Personal app guidance

- Follow the [hub guidance](https://github.com/Signal-Echo-Security/hub-signalecho/blob/develop/AGENTS.md). Keep personal journeys in this app and corporate journeys in iot.EraX Console.
- Maintain all Harbor Lens locales and RTL. Use shared contract codes and language metadata. Use logical CSS properties and localized accessible names.
- Keep browser and Tauri entry points on the same React code. Add device APIs through narrow adapters. For future sign-in reuse iot.EraX identity and use a system browser in native flows.
